# Aurix Landing Page

Landing page desarrollada en React + Vite para el sistema de monitoreo IoT Aurix.

## 🚀 Deploy

Sitio en vivo: [https://xhandlr.github.io/water-quality-monitoring/](https://xhandlr.github.io/water-quality-monitoring/)

## 🛠️ Desarrollo Local
```bash
npm install
npm run dev
```

## 📦 Build
```bash
npm run build
npm run preview
```

## 🌐 Deploy (GitHub Pages)
```bash
npm run deploy
```
